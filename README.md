# 道 Sokōdo

**La voie du fond solide.**  
Programme de reconstruction lombaire en 3 phases — 12 semaines — puis entretien continu.

---

## À propos

Sokōdo est une Progressive Web App (PWA) mobile conçue pour les personnes souhaitant renforcer et entretenir leur dos après une douleur lombaire. Le programme est progressif, guidé par la voix, et ne nécessite aucun équipement.

Le coach vocal **Papa Ninja** accompagne chaque séance.

---

## Fonctionnalités

- **3 phases progressives** — Fondation (S1–S4), Progression (S5–S8), Maîtrise (S9–S12)
- **Validation par séances réelles** — une semaine est validée après 3 jours d'entraînement distincts
- **Annonces vocales** — guide vocal pendant les temps de mise en place
- **Mode Entretien** — programme continu après les 12 semaines
- **Score Sokōdo** — progression visible sur tout le programme (plafond 500 pts)
- **Guide intégré** — fiches détaillées pour chaque exercice
- **Export / Import** — sauvegarde de la progression en JSON
- **Rappels calendrier** — fichier .ics à importer dans l'app Calendrier
- **PWA installable** — fonctionne hors ligne, s'installe sur l'écran d'accueil

---

## Programme

| Phase | Semaines | Intensité |
|-------|----------|-----------|
| Fondation | 1 à 4 | Base, 1 tour |
| Progression | 5 à 8 | +1 tour |
| Maîtrise | 9 à 12 | +1 tour, +2 répétitions |
| Entretien | 13+ | Phase 3 maintenue, 3 séances/semaine |

---

## Installation

1. Ouvrir l'URL GitHub Pages sur iPhone ou Android
2. Safari → Partager → **Sur l'écran d'accueil**
3. L'app s'installe comme une application native
